# 阪神バス 尼崎市内線 GTFS

阪神バス（尼崎市内線：幹線・地域線 44系統）のGTFSを生成するためのデータとスクリプトです。
停留所CSVの42系統に、駅探に掲載されている 12A・52A を加えています。

## ビルド

```bash
python3 scripts/build_gtfs.py
```

`dist/` に各 .txt と `hanshin_amagasaki_gtfs.zip` が出力されます。外部ライブラリは不要です。

## 入力データ（data/）

- `stops_source.csv` … 停留所エクセル（CSV）。stop_id は尼崎市内線が通る行を上から順に `S001`… と採番します。
- `routes.csv` … 系統一覧。`source_label` は停留所CSVの routes 列の表記です。
- `calendar.csv` … `holiday_service` 列に、祝日にその曜日のダイヤの代わりに走らせる service_id を書きます。
- `timetables/index.csv` … 時刻表ファイルの一覧です。

  ```
  file,route_short_name,direction_id,service_id,trip_headsign
  12_0_weekday.csv,12,0,weekday,阪神尼崎行
  ```

- `timetables/<file>.csv` … 経路順の停留所×便の時刻表です（`TEMPLATE.csv.example` を参照）。
  - 1行目は `stop_name,便1,便2,...` です。
  - 任意の `_headsign` 行で、便ごとに行先を上書きできます。
  - 時刻が空欄の停留所は、その便では停車しない扱いになります。
  - 同名の標柱が複数ある停留所（東園田8丁目、城ノ堀、小田南生涯学習プラザ前）は、系統から自動判別します。判別できない場合は `城ノ堀#S087` のように stop_id を指定してください。

## 時刻の出典と作り方（駅探）

`tools/ekitan/` のスクリプトで、駅探の停留所別時刻表ページ（robots.txt で許可された、クエリなしのURL）を取得しています。

- 駅探の停留所別時刻表は、各便に便IDが付いています。同じ便IDの時刻を全停留所から集めて、1便分の停車時刻を組み立てています。
- 取得できるのは実行日のダイヤだけです（曜日の切り替えはクエリ付きURLで、robots.txt により取得禁止）。平日・土曜・日祝のダイヤは、それぞれその曜日に `tools/ekitan/run.sh weekday|saturday|holiday` を実行して取り込みます。
- 終点は発車時刻が無いため、到着時刻を推定しています。推定には次の順で、使えるものを使います。
  1. 他の便の同じ区間の所要時間
  2. 逆方向の所要時間（距離からの推定と大きくずれない場合だけ）
  3. 距離（直線×1.3、時速15km）
- 同じ「分」に複数の停留所が並ぶ場合は、前後を含めた走行距離が最短になる順に並べています。推定時刻は時刻表CSVで末尾に `*` が付き、stop_times.txt では `timepoint=0` になります。
- **駅探の規約により、データの加工・再利用・再配布には駅探の許可が必要です。** 公開・提供する場合は、阪神バスからのデータ提供を受けてください。

### 停留所名の対応（駅探 → 停留所CSV）

表記ゆれは自動で吸収しています（ケ/ヶ、全角/半角、末尾の「（尼崎市）」など）。それ以外は `tools/ekitan/assemble.py` の `ALIAS` に定義しています。照合には、国土数値情報 バス停留所データ（P11、2022年、兵庫県）を使いました。同じ名前の停留所の系統・位置・前後の停留所を確認しています。

| 駅探の名前 | 停留所CSVの名前 | 根拠 |
|---|---|---|
| JR猪名寺(東口)、JR猪名寺(西口) | JR猪名寺 | CSV・P11ともに1か所だけ（東口・西口の区別なし） |
| アミング潮江 / 園田学園大学 / 時友 / 武庫小学校前 / 竹谷小学校 | アミング潮江前 / 園田学園女子大学 / 時友（高架下） / 武庫小学校 / 竹谷小学校前 | 表記違い。系統が一致 |
| 労災病院 / 昭和通８丁目 / 稲葉荘１丁目 | 労災病院前 / 昭和通八丁目 / 稲葉荘一丁目 | 表記違い。系統が一致 |

- 停留所CSVに無い停留所（伊丹市）：野間西、近畿中央病院。P11の座標を `data/stops_extra.csv` に入れています。
- 生成したGTFSで次の点を確認済みです。
  - 使用した停留所は、すべてP11に同じ名前で存在する。
  - 座標の差は50m以内。
  - 隣り合う停留所の距離と所要時間に不自然な組み合わせが無い。例外は終点手前のターミナル周回（昭和通→阪神尼崎［北］の約7分など）で、駅探の実績時刻と一致している。
- 停留所CSVにあり、現在の駅探の経路に無い停留所：尼崎東警察署前、潮江1丁目（48-2・58系統）、武庫西生涯学習プラザ前（41-2系統）、椎堂［20系統］、東園田3丁目［20系統］（20系統は通常の椎堂・東園田3丁目に停車）。
